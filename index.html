O que é o Problema da Mochila?

Dados N itens, cada um com um peso e um valor, e uma mochila com capacidade máxima W, o objetivo é escolher quais itens incluir para maximizar o valor total sem ultrapassar a capacidade.

A tabela dp[i][w] representa o maior valor possível usando os primeiros i itens com uma mochila de capacidade w.

Recorrência da PD
dp[i][w] = dp[i−1][w] se peso[i] > w dp[i][w] = max( dp[i−1][w], valor[i] + dp[i−1][w − peso[i]] ) se peso[i] ≤ w

📈 Maior Subsequência Crescente (LIS)

Encontre a maior subsequência em ordem estritamente crescente

O que é a LIS?

Dada uma sequência de números, encontre a subsequência mais longa onde cada elemento é estritamente maior que o anterior.

dp[j] = comprimento da maior subsequência crescente terminando no índice j.

Recorrência da PD
dp[j] = 1 (caso base) dp[j] = max(dp[i] + 1) para todo i < j onde seq[i] < seq[j] Resposta = max(dp[j]) para todo j

📅 Weighted Interval Scheduling

Selecione intervalos sem sobreposição para maximizar o peso total

O que é o WIS?

Dados N intervalos, cada um com início, fim e peso, selecione um subconjunto de intervalos sem sobreposição que maximize o peso total.

dp[j] = maior peso usando os j primeiros intervalos (ordenados por tempo de término). p(j) = índice do último intervalo compatível com j.

Recorrência da PD
dp[0] = 0 dp[j] = max( peso[j] + dp[p(j)], dp[j−1] )

🧬 Alinhamento de Sequências

Encontre o alinhamento ótimo entre duas sequências usando PD

O que é o Alinhamento de Sequências?

Dados duas sequências e pontuações para match, mismatch e gap, calcule a pontuação máxima de alinhamento.

dp[i][j] = pontuação ótima alinhando os primeiros i chars de seq1 com os primeiros j chars de seq2.

Recorrência da PD
dp[i][0] = i × gap, dp[0][j] = j × gap dp[i][j] = max( dp[i−1][j−1] + score(s1[i],s2[j]), dp[i−1][j] + gap, dp[i][j−1] + gap )

🗺️ Bellman-Ford

Caminho mais curto de fonte única, com suporte a arestas negativas

O que é o Bellman-Ford?

Dado um grafo direcionado com pesos (possivelmente negativos) e um vértice fonte, calcule a distância mínima até todos os outros vértices.

O algoritmo relaxa todas as arestas |V|−1 vezes. Se ainda for possível reduzir distâncias após isso, existe um ciclo negativo.

Recorrência
dist[fonte] = 0, dist[v] = ∞ para demais vértices Para cada iteração e cada aresta (u→v, w): se dist[u] + w < dist[v]: dist[v] = dist[u] + w
